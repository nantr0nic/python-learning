# TCPClient
Simple TCP Client. Sends an ASCII message to a TCP Server through port 31173.
Specifically, the TCP server program in tcpserver.py (go up a folder).

## Use:
In terminal, run:
```python3 tcpclient.py <hostname> <message>```
For example:
```python3 tcpclient.py 127.0.0.1 "This is a test message"```
