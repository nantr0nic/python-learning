# UDPClient
Simple UDP Client. Sends an ASCII message to a UDP Server through port 31173.
Specifically the UDP server in udpserver.py (go up a folder).

## Use:
In terminal, run:
```python3 udpclient.py <hostname> <message>```
For example:
```python3 udpclient.py 127.0.0.1 "This is a test message"```
